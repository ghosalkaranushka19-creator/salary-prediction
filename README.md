# Salary Prediction

This is a Machine Learning project that predicts salary based on user input.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Project Files

- salary_prediction_deployment.py
- salary_prediction_model.pkl
- label_encoder.pkl
- requirements.txt

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the Streamlit app:

streamlit run salary_prediction_deployment.py
